Why each theme declares its own text colour. antd puts white on the accent by default. That is fine on Graphite and Iris and fails contrast badly on Lime and Sea. Every theme carries an onAccent value, which is why the Lime and Sea buttons above use near black text.

03Polling limits

The shared shell added pollers to every route, so this got measured rather than assumed.

PollerWasNow
Tracked profiles10s30s
Status and breaker5s5s
Profile metadata4s10s

Hidden tab total0.80 req/s0.00 req/s
None of this touches Instagram. Polling only reads SQLite. Instagram traffic is gated by the single worker thread and the pacer, and ensure is idempotent: forty polls over four items produced exactly four jobs.

04Enhancements shipped

  • Three pane layout. Profile rail with lookup and tracked accounts, contact sheet grid with the newest post featured at double size, inspector carrying metadata and the download form.
  • Theme switcher. Five accents plus light and dark, persisted to the browser.
  • Density toggle. Comfortable and compact grid sizes.
  • Queue drawer. The worker queue was in the API from day one and had never been shown.
  • Manual refresh. A refresh control in the header, so freshness is not purely a timer.
  • Skeletons. Grid shaped placeholders instead of the word "Loading".
  • Breaker banner in the shell. Visible on every screen rather than only where the old component was mounted.

05Bugs found by looking

Every one of these was found by running the interface, not by reading it. None were caught by a green unit suite.

DefectWhy it mattered
Single selection had no download formYou could only download two or more posts. The most basic action was missing.
Lookup button was display: noneReachable only by pressing Enter. Invisible to mouse and assistive tech.
Saved selections inside the selection blockClearing the selection made them unreachable, so a saved set could never be loaded back.
Preview and checkbox only existed on hoverUnreachable by keyboard or touch. An element that is not in the DOM cannot be focused.
Hidden tab never fetched at allMy own visibility optimisation skipped the first fetch, so a background tab rendered a half populated screen.
opacity: 0 control still took clicksEvery tile had an invisible button swallowing clicks meant for its neighbour.
Grid capped at 120 posts"Load more" kept indexing, but anything past the newest 120 was invisible.
e2e script deleted its data before killing serversA stale API holding the SQLite file aborted every run under set -e.
