A tool that tells you what it is doing

Every screen below is the real proposed interface, rendered at full fidelity. Nothing here is built yet. The current UI shows a bare "Loading" string, static text badges, and a four second poll that makes a running fetch look frozen.

product UI, not a landing page VARIANCE 3 MOTION 4 DENSITY 6 Geist + Geist Mono one accent, semantic state colours

One toolbar instead of two stacked control rows. Worker state lives in the top bar where it is always visible. Tiles carry their own state so you never have to guess which of forty items is stuck.

08Open questions
